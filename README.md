# Eterna Marketplace
A full-stack web application built on the MERN stack for the exchange of rare and exclusive products.

## Technical Implementation
* Backend Development: Designed a RESTful API using Node.js and Express.js to handle complex product schemas and user transactions.
* Database Management: Implemented a non-relational database structure with MongoDB for flexible product attributes.
* Frontend Engineering: Built a responsive, state-driven user interface using React.js to ensure a seamless user experience.
* Authentication: Integrated secure user authentication and account management protocols.
* Deployment: Managed the application hosting and environment configuration through Firebase.

## Environment and Dependencies
* Stack: MongoDB, Express.js, React.js, Node.js
* Hosting: Firebase
